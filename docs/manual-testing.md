# Blog 人工测试清单

本文记录当前 Workspace 风格博客的人工验收项目。自动构建不会替代以下测试。

## 2026-09-17 Workspace 风格重构

### 桌面布局

- [ ] 在宽度 1440px 或更宽窗口打开首页，确认 Logo 与标题位于顶栏左侧，一级导航位于顶栏中间，右侧没有额外菜单，只有内容区滚动。
- [ ] 打开文章、标签和文章详情，确认顶栏下方的水平二级导航显示且当前项正确。
- [ ] 确认主标题、模块、列表和页脚使用同一集中内容轨道。
- [ ] 向下滚动超过约 96px，确认标题收拢；回到顶部后重新展开。
- [ ] 向下滚动超过约 280px，确认返回顶部按钮出现并可用。

### 窄屏与缩放

- [ ] 分别在 980px、760px、520px 和 320px 宽度检查所有路由，无页面级横向滚动。
- [ ] 在 980px 宽度确认一级导航仍显示文字；在 760px 以下确认导航隐藏文字但保留图标、键盘提示和可访问名称，二级导航仍可横向访问。
- [ ] 在 520px 以下确认顶栏文字隐藏，图标、按钮、文章行和作者信息没有重叠。
- [ ] 在浏览器 200% 缩放下检查导航、标题、代码块和操作按钮。

### 内容与交互

- [ ] 首页只显示真实的 4 篇文章，标题、图片、日期、阅读时间和标签链接正确。
- [ ] 从全部文章打开每篇文章，确认封面、正文、代码块和图片正常显示。
- [ ] 在标签页切换筛选并使用浏览器前进/后退，确认 URL、计数和结果同步。
- [ ] 在文章页滚动，确认阅读进度和当前目录项同步更新。
- [ ] 测试目录跳转、返回顶部、分享文章和评论区跳转。
- [ ] 滚动到评论区附近，确认 Giscus 能加载；网络失败时正文仍可阅读。
- [ ] 打开友链并检查外部链接在新标签页打开。

### 键盘与辅助功能

- [ ] 仅使用 Tab、Shift+Tab、Enter 和方向键完成主要导航、标签筛选和文章操作。
- [ ] 确认“跳到主要内容”链接在获得焦点时可见且有效。
- [ ] 确认所有图标导航均有可读名称，焦点环清晰，当前状态不只依赖颜色。
- [ ] 启用“减少动态效果”和系统强制色后检查内容仍可用。

### 本地启动

- [ ] 双击根目录 `start-local.bat`，确认默认地址 `http://127.0.0.1:4321/` 可访问。
- [ ] 使用 `start-local.bat -Port 4322`，确认端口参数生效。
- [ ] 制造启动错误，确认控制台保留错误信息并暂停。

# Blog 人工测试清单

本文记录当前 Workspace 风格博客的人工验收项目。自动构建不会替代以下测试。

## 2026-09-17 Workspace 风格重构

### 桌面布局

- [ ] 在宽度 1440px 或更宽窗口打开首页，确认头像、首页、文章、友链和 GitHub 五个项目整体位于顶栏中央，没有站点标题或额外菜单，只有内容区滚动。
- [ ] 依次点击五个顶栏项目，确认唯一的圆角选择层连同顶栏上缘标记平移到目标，而不是旧项隐藏、目标项重新显示；头像不跳转，GitHub 直接打开配置的地址。
- [ ] 在首页、文章与友链间往返，确认选择层经过目标项目时，目标图标始终位于选择层上方；整组导航不再因新旧快照叠加而短暂变亮或闪烁。
- [ ] 确认首页、文章和 GitHub 使用新的实心 SVG，友链继续使用原有线性 SVG；不同状态下图标颜色跟随前景色。
- [ ] 确认指针悬停导航约 150ms、键盘聚焦时显示提示，Escape 可以关闭提示。
- [ ] 打开文章、标签和文章详情，确认顶栏下方的水平二级导航显示且当前项正确。
- [ ] 确认主标题、模块、列表和页脚使用同一集中内容轨道。
- [ ] 向下滚动超过约 96px，确认标题收拢；回到顶部后重新展开。
- [ ] 向下滚动超过约 280px，确认返回顶部按钮以 72 × 72px 强调色圆角方块出现；悬停时上移并增强阴影，点击后立即回到顶部。

### 窄屏与缩放

- [ ] 分别在 980px、760px、520px 和 320px 宽度检查所有路由，无页面级横向滚动。
- [ ] 在所有宽度确认头像与四个图标入口保持整体居中，桌面 SVG 约为 25px 且头像为 39px；在 760px 以下确认图标继续缩小、项目尺寸与间距收紧、返回顶部按钮缩为 64 × 64px，二级导航仍可横向访问。
- [ ] 在 520px 以下确认顶栏文字隐藏，图标、按钮、文章行和作者信息没有重叠。
- [ ] 在浏览器 200% 缩放下检查导航、标题、代码块和操作按钮。

### 内容与交互

- [ ] 在 05:00、12:00、18:00 与 23:00 四个时间段检查首页问候语；确认大型标题下没有装饰性说明。
- [ ] 首页只显示真实的 4 篇文章，每行包含封面图片、标题、摘要、Tags 和三点菜单，不显示发布日期、阅读时间或直接操作按钮。
- [ ] 双击文章行的空白、标题或摘要区域进入文章；单击 Tags 进入对应的已选中标签筛选结果。
- [ ] 标题悬停时不单独变色或出现下划线；Tags 使用圆角边界 hover 状态且没有下划线。
- [ ] 三点菜单一次只打开一个；测试外部点击、Escape、上下方向键、Home/End、菜单操作和焦点返回。
- [ ] 确认首页“关于”标题简洁，内容为闭合圆角卡片；GitHub、邮件联系和“查看更多”三个入口可用，页脚只保留版权信息。
- [ ] 确认“关于”三个入口默认没有可见边框；悬停与键盘聚焦时背景色和文字前景色同时改变。
- [ ] 在 761px 及以上确认“全部文章”固定为三列 Grid，在 760px、520px、320px 下确认切换为单列且无横向溢出；页面不再显示“按标签筛选”按钮。
- [ ] 确认 Grid 图片与卡片外框之间存在间距；标题固定两行、简介固定四行、Tags 固定一行，较长内容被裁剪且不会撑高单张卡片。
- [ ] 确认标题和图片没有独立链接样式；双击卡片空白、图片、标题或简介可以打开文章，Tag 单击与三点菜单不会误触发卡片双击。
- [ ] 确认文章 Grid 的 Tags 默认没有可见边框；悬停或键盘聚焦时使用与首页 Tags 相同的圆角边界和浅强调背景。
- [ ] 分别检查首页、全部文章、标签、友链和文章详情，确认复用页脚且都只显示 `© 2026 EVIGILA`，没有返回按钮。
- [ ] 从全部文章打开每篇文章，确认封面、正文、代码块和图片正常显示。
- [ ] 在标签页确认右侧文章采用与首页相同的行式结构，顶部不显示筛选提示或篇数统计。
- [ ] 在桌面矮窗口滚动左侧标签栏，确认全部标签均可访问；右侧文章和页脚继续随页面主滚动。标题收拢后左栏可用高度增加，内容不会被 sticky 区域裁掉。
- [ ] 在标签页切换筛选并使用浏览器前进/后退，确认 URL、选中标签和结果同步；筛选后不会出现旧列表高度造成的大块空白，也不会停留在结果内容之外。
- [ ] 在 980px 以下确认标签栏改为横向滚动，不产生第二个纵向滚动区，并能自动露出当前选中的标签。
- [ ] 在文章页滚动，确认阅读进度和当前目录项同步更新。
- [ ] 测试目录跳转、返回顶部、分享文章和评论区跳转。
- [ ] 滚动到评论区附近，确认 Giscus 能加载；网络失败时正文仍可阅读。
- [ ] 在 761px 及以上打开友链，确认联合 Grid 每行三张卡片且卡片之间没有间隙；四个友链排列为首行三个、次行左侧一个，并共享同一外框、圆角和单线分隔。
- [ ] 确认友链卡片不再显示序号等装饰性文案，名称、简介、域名和外链提示没有溢出；整卡悬停与键盘焦点状态清晰，外部链接在新标签页打开。
- [ ] 在 760px、520px 和 320px 下确认友链变为单列联合列表，没有双重边框或页面级横向滚动。

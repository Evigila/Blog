# 变更日志

本文按时间追加记录项目的重要实现变更和验证边界。

## 2026-09-22

- 新增友链「Yuriel404的小窝」，链接至 `https://blog.simpleclover.top/`，简介为「QAQ」。
- 将 Astro、WPF 窗口修复、WPF 自定义 Main 与 Saas 四篇文章的封面切换为 picX 托管链接，避免继续依赖站内 `/images/posts/` 路径。
- 将友链「Yuriel404的小窝」的简介由「QAQ」更新为「希望可以逐渐修炼成满级人类」。
- 删除四张零引用的本地文章封面，并清理未使用的导航定义、数据字段、图标分支、样式令牌和 Astro 图片服务配置；保留仍在使用的头像、关于页图片、源码文件与依赖。
- 统一首页、全部文章、标签结果与文章详情的封面展示比例为 `16:9`，移除移动端和网格卡片中导致图片趋近方形的固定高度。
- 修复窄屏导航页标题收拢时重新套用桌面端 `104px` 最小高度的问题，使标题字号、内边距和标题行高度同步缩小，不再在慢滚越过阈值时回弹或保留多余空间。
- 修复文章详情封面只覆盖宽度、却继续继承 HTML `height="720"` 而形成桌面偏胖和手机端高窄的问题；改由外层容器严格计算 `16:9` 高度，并用 `contain` 完整显示非标准比例的源图。
- 自动验证：`npm run build` 成功；未执行浏览器视觉或交互自动化，人工测试项目记录在 `docs/manual-testing.md`。

## 2026-09-17

- 将博客页面重构为 Colligere Workspace 风格，同时保留 Evigila 的品牌、现有内容和路由。
- 新增固定顶栏、一级图标导航、文章二级导航、唯一内容滚动区、标题收拢和返回顶部行为。
- 统一 Segoe UI、17px 普通文字、绿色主题令牌、1180px 内容轨道、平面列表和响应式断点。
- 首页移除轮播示例数据，只展示内容集合中的真实文章。
- 文章页重建为集中正文与页内目录布局，保留阅读进度、目录跳转、分享和 Giscus 懒加载。
- 锚点跳转会为收拢后的固定标题预留空间；标签筛选在历史切换时恢复 Workspace 内容滚动区的位置。
- 根目录 `start-local.bat` 继续负责一键启动；失败时保留控制台错误并暂停。
- 自动验证：`npm run build` 成功生成 18 个静态页面。
- 未执行浏览器视觉或交互自动化；人工测试项目记录在 `docs/manual-testing.md`。
- 根据博客场景调整 Workspace 导航：移除左侧一级导航栏与顶栏右侧菜单，将一级导航集成到顶栏中间，并把文章二级导航改为顶栏下方的水平导航。
- 一级导航进一步收敛为 Colligere 风格的纯图标圆角方形项，并把当前项边缘标记移动到顶栏上缘。
- 删除页面大型标题下的装饰性说明，恢复首页分时动态问候，并移除重复的文章入口与文章计数。
- 首页近期文章精简为标题、摘要和 Tags；整行支持双击打开，Tags 保持独立筛选导航，其他操作统一进入三点菜单。
- 顶栏移除站点标题，将头像与首页、文章、友链、GitHub 四个入口整体居中；选中态重构为始终存在并在项目间平移的单一浮层。
- 首页文章列表恢复封面图片；“关于”改为闭合圆角卡片并精简入口文案，首页页脚仅保留版权。
- 返回顶部按钮对齐 Colligere Workspace 的尺寸、颜色、圆角、阴影、响应式规格与即时滚动行为。
- 修复跨页面平移选择层覆盖目标导航图标的问题：导航前景作为独立转场层，始终绘制在选择层上方。
- 首页、文章与 GitHub 导航替换为指定的实心 SVG；“关于”入口改为无可见边框、悬停时同时切换背景与前景。
- “全部文章”新增独立 Grid 变体，只展示封面、标题、简介与 Tags，标签筛选结果继续保留列表变体。
- 新增可复用标准页脚组件，首页、目录、标签、友链与文章详情统一只显示版权信息。
- 消除导航前景新旧快照叠加造成的整体高亮闪烁，并适当缩小顶栏 SVG 与头像尺寸。
- 全部文章 Grid 最终固定为桌面三列、窄屏单列；卡片改为内缩图片、两行标题、四行简介和单行 Tags，并通过整卡双击与三点菜单打开文章。
- 移除全部文章页重复的“按标签筛选”按钮；内容标签结果改为首页同型列表并删除可见筛选提示与文章计数。
- 修复标签页滚动：移除旧结果高度保留和旧滚动位置恢复，右侧继续使用页面主滚动，桌面左侧标签栏只在溢出时进行受限滚动，窄屏改为横向滚动。
- 友链页改为桌面三列、窄屏单列的联合 Grid；四个站点按三加一排列，共享统一外框与圆角，并删除序号等装饰性文案。
- 新增作者“关于”页，顶栏头像与首页“查看更多”均改为进入该页面；个人信息、社交平台、游戏占位和编程项目使用三列联合图标 Grid，并以是否配置链接自动区分彩色可用项与灰色待补充项。
- 关于页社交与技术标识替换为官方或 Simple Icons 路径，WPF 与 WinUI 使用微软项目维护的专属矢量，并放大所有图标；新增统一的 `17px` Colligere 风格图标 Tooltip，取代浏览器原生提示。
- 文章详情右侧检查栏拆分为目录、文章信息和文章导航三张独立浮动卡片；桌面端固定停靠在标题栏下方并保持较低层级，长目录支持独立滚动与活动章节自动跟随，中窄屏恢复静态卡片布局，并隐藏文章页重复的 Shell 返回顶部按钮。
- 精简文章浮动检查栏：移除重复作者信息和所有内部滚动，目录按视口高度自适应为一至四列紧凑布局，并在较矮窗口扩大右栏，确保目录、标签与导航卡片同时固定可见。
- 依照最终文章右栏规范，将目录恢复为单列并只允许目录列表滚动；外层浮窗继续固定且禁止滚动，导航收敛为带自定义提示和可访问名称的三个纯图标按钮。
- 修复分享脚本以 `textContent` 覆盖 SVG 的问题：分享按钮始终保留图标，仅更新 Tooltip、无障碍名称和复制成功状态；三个导航按钮最终采用无可见边框的圆角样式，悬停与状态反馈只切换背景和图标前景。
- 修复文章评论区加载：验证公开仓库、Discussions 与 Giscus 分类配置有效，移除不稳定的自定义 IntersectionObserver 注入流程，改用官方脚本及 `data-loading="lazy"` 直接挂载评论 iframe。
- 固定文章目录的 Grid 行轨道与顶部对齐方式，消除章节数量不同时的动态间距；首页、全部文章和标签结果统一由整行或整卡单击进入文章，并继续隔离 Tags 与三点菜单交互。
- 文章目录项增高到至少 `36px` 并使用固定 `4px` 间距；目录卡改为内容驱动高度，短目录自然收缩，只有长目录超过视口剩余空间时才启用列表滚动。
- 完善作者主页资料：QQ 改为打开好友二维码的中央模态框，Steam 与 Discord 接入真实外链，其余未配置社交项继续保持灰色；喜爱的游戏替换为 Minecraft、Terraria 与 Dota 2 的本地位图。
- 将 Minecraft 游戏图由带版本副标题的 Xbox 横幅修正为 Java Edition 经典立体草方块图标。
- 按最终素材替换三张喜爱游戏图片，并让图片无间距铺满联合 Grid；Dota 2 宽图通过居中 `cover` 在正方形格子内裁剪。

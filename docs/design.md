# Blog 设计规范

本文是 Evigila 博客页面设计与交互的现行规范。实现参考 Colligere Workspace 的视觉语言与页面合同，但不复制 Colligere 的业务模块、品牌标识或身份模型。

## 1. 视觉令牌

- 全部界面使用 `Segoe UI`。普通正文、导航、按钮、元数据和标签统一为 `17px`。
- 主色为 `#153A32`，强调色为 `#16745F`；画布、边线、悬停和浅强调表面由主题色混合白色生成。
- 页面主标题使用响应式 `42–68px`；窄窗口使用 `36–50px`。区块标题使用响应式 `28–40px`。
- 标准控件高度为 `48px`，紧凑行操作为 `36px`。控件圆角为 `12px`，普通表面圆角为 `16px`。
- 页面不实现不完整的深色主题，不使用小字号、渐变、玻璃效果或阴影卡片表达层级。

## 2. Shell 与导航

- 页面使用固定 `68px` 顶栏；头像、首页、文章、友链与 GitHub 五个项目作为一个整体居中，不显示站点标题或额外菜单。头像保留按钮语义但暂不跳转，GitHub 直接离开站点。只有 `.workspace-stage` 纵向滚动。
- 文章、标签和文章详情属于文章模块，在顶栏下方显示水平二级文字导航。
- 内容最大宽度为 `1180px`，水平边距随窗口宽度在 `24–72px` 范围内变化。
- 一级导航使用 `25px` SVG 纯图标和 `55 × 55px` 圆角方形操作面。选中背景、内描边与顶栏上缘 `28 × 4px` 标记属于唯一的独立浮层；浮层始终可见，通过 `transform` 在项目间平移，不允许每个项目分别切换背景。每项保留可访问名称，并提供可由指针、键盘和 Escape 控制的单一提示。
- 跨页面导航时，选择层与完整导航前景分别建立转场层；导航前景始终绘制在选择层之上，并且只显示新页面前景快照，避免新旧半透明图标叠加造成整体闪烁。首页、文章与 GitHub 使用指定的 `24 × 24` 实心 SVG 路径，友链保持线性图标。
- 页面滚动超过 `96px` 后收拢标题，回到 `24px` 内展开；超过 `280px` 显示与 Colligere Workspace 一致的强调色返回顶部按钮：桌面 `72 × 72px`、窄屏 `64 × 64px`，点击后立即回到顶部。
- 在 `760px` 以下，一级导航项收紧为 `44 × 44px`。二级导航始终保持横向可达。

## 3. 页面结构

- 首页只展示真实文章，不使用示例内容填充。首页主标题使用按本地时间变化的问候语，不显示独立副标题或重复操作。
- 页面大型标题下不得显示装饰性描述、口号、计数或重复说明；SEO 描述可以保留在不可见元数据中。
- 近期文章采用闭合边界和平面行，每行显示封面图片、标题、摘要与 Tags。标题不单独产生 hover 或链接样式，Tags 使用无下划线的圆角边界交互。
- 文章行双击时打开文章；Tags 的单击导航保持独立。行内只允许 `36 × 36px` 三点菜单，具体操作在菜单中显示，不直接排列操作按钮。
- 首页“关于”使用完整边框、圆角和表面底色组成闭合卡片；保留 GitHub、邮件联系和“查看更多”入口。三个入口默认无可见边框，悬停或聚焦时同时改变背景色与前景色。
- 全部文章页使用三列 Grid 卡片，`760px` 以下切换为单列。卡片图片与外框保留间距；标题固定两行、简介固定四行、Tags 固定一行并裁剪溢出。标题和图片不提供独立文章链接，双击卡片打开文章，键盘入口统一放入三点菜单。Tags 与首页一致：默认边框透明，悬停或聚焦时显示 `10px` 圆角边界与浅强调背景。
- 全部文章页不重复显示“按标签筛选”按钮，标签入口由文章模块次级导航提供。
- 标签页保留可直达静态 URL 和客户端无刷新筛选；筛选控件保持 `48px` 高度，右侧不显示重复的筛选标题或文章计数。文章结果采用与首页一致的图片、标题、简介、Tags、整行双击和三点菜单样式。
- 标签页继续使用 `.workspace-stage` 作为唯一页面滚动区；右侧结果和页脚自然参与主滚动。桌面端左侧标签栏保持 sticky，但以剩余视口高度为上限，仅在溢出时独立滚动；标题收拢后同步调整 sticky top。`980px` 以下标签栏改为单行横向滚动。筛选不得保留旧结果高度或恢复失效的旧滚动位置。
- 友链页使用三列联合 Grid：所有站点共享单一外框与圆角，卡片之间无间距，仅用一条内部边界分隔。卡片保留名称、简介、域名和外链提示，删除序号等装饰性文案；末行不足三项时从左侧依次排列，`760px` 以下改为单列联合列表。
- 文章详情页使用真实文章标题，上方只显示“全部文章”父链接。正文与右侧页内目录共享集中内容区域。
- 文章目录显示阅读进度并高亮当前章节；内容宽度不足时目录移动到正文上方，不压缩正文。
- 评论区继续使用 Giscus，进入邻近视口后加载；分享、返回顶部和评论区跳转必须保持可操作。
- 首页、全部文章、标签、友链与文章详情复用同一个标准页脚，页脚只显示 `© 2026 EVIGILA`，不包含返回按钮。

## 4. 响应式与无障碍

- 主要断点为 `980px`、`760px` 和 `520px`，最小宽度为 `320px`。
- 代码块只在自身区域横向滚动，页面不得产生横向溢出。
- 所有图标入口必须具有可读名称；键盘焦点使用主题焦点色且不能只依赖颜色表达状态。
- 动画必须尊重 `prefers-reduced-motion`，强制色模式下保持边界与焦点可见。
- 视觉和键盘行为必须通过人工测试确认；静态构建成功不能替代浏览器验收。
